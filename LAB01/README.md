# LAB01 – Etap I: instalacja WordPress + WooCommerce w Local

Sklep internetowy **KawaNaKlik** (scenariusz: sklep internetowy, dane wyłącznie syntetyczne).

- `Sprawozdanie_APPDB_KawaNaKlik.pdf` – sprawozdanie ze zrzutami ekranu
- `sprawozdanie.html` – źródło sprawozdania
- `screeny/` – zrzuty ekranu z instalacji (Local, WordPress, WooCommerce)
- `kod/seed_kawanaklik.php` – generator danych syntetycznych (`wp eval-file`)
- `kod/utworz_strone_local.sh` – utworzenie strony w Local przez API GraphQL
- `dane_testowe/` – eksport produktów, klientów i zamówień (CSV)

Środowisko: Local 10.2 · WordPress 7.1.3 · WooCommerce 11.2.1 · PHP 8.2.29 · MySQL 8.4.0 · nginx 1.26.1
